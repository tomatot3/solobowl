# 当前项目内容

## 用户路径

首页通过菜名、食材和分类找饭。一餐详情给出份量、用料、锅具、前提和替换入口。做饭页展开准备、下锅和收尾，计时按实际经过时间显示。

“留到晚上”保留一份想做的饭；“我的做法”保存具体配比；最近浏览只是回看入口。没有库存勾选、购物核销、完成打卡或自动饮食日志。

## 内容清单

保留 12 道原有菜：酸汤豆腐米线、番茄鸡蛋盖饭、酸辣土豆丝、葱油拌面、芝麻酱拌面、白菜鸡蛋汤面、香菇青菜焖饭、南瓜小米粥、萝卜豆腐汤、莲藕香菇汤、紫菜蛋花汤、青椒豆腐盖饭。

补充鸡蛋清汤面、番茄鸡蛋汤面和白菜无蛋版本。共有 14 个内容入口、15 个完整版本，均编写一人份与两人份。土豆丝作为配菜，四项汤粥作为搭配。

三篇厨房随记介绍家常口味、一锅汤粥和单锅做饭顺序。

## 代码主链

`content/build.cjs → src/content.js → resolver.js → views.js / app.js`

公共方案、保存快照和当前烹饪使用相同的 Plan 结构。步骤引用材料 ID 取用量，避免单独修改页面数字。保存的个人方案不会自动跟随公共菜谱升级。

`store.js` 处理浏览器保存、旧资料和备份导入；`timer.js` 根据结束时间戳显示倒计时；服务器不保存用户资料。
